Política de Privacidad

Última actualización: 23 de noviembre de 2026

Agendador es una aplicación de uso estrictamente personal operada por Erwin Risco. Esta política describe cómo se manejan los datos.

1. Datos que se acceden

Agendador accede exclusivamente a la API de Google Calendar de la cuenta del propietario (erwinrisco@gmail.com) para leer y escribir eventos. No accede a datos de terceros.

2. Almacenamiento de tokens

Los tokens OAuth se almacenan localmente en un servidor propio con permisos restringidos. No se comparten con terceros ni se transmiten fuera del entorno controlado por el propietario.

3. Datos de terceros

Agendador no recopila, almacena ni comparte datos de otros usuarios. Es una herramienta de uso individual.

4. Comunicación

La interacción se realiza a través de un bot de Telegram privado. Los mensajes se procesan localmente y no se reenvían a servicios externos más allá de la API de Google Calendar cuando es necesario para crear o consultar eventos.

5. Contacto

Para cualquier consulta sobre privacidad: erwinrisco@gmail.com.
