Agendador

Asistente personal de agenda avanzado · Bot de Telegram

Agendador es una aplicación de uso estrictamente personal que actúa como un asistente de agenda a través de Telegram. Gestiona el calendario de Google, el sistema de pendientes y la coordinación de una flota de bots (Batallón) mediante un patrón de comunicación asíncrona.

¿Qué hace?

  • 📅 Agenda: Lee y escribe eventos en Google Calendar.
  • ✅ Pendientes: Sistema de tareas con base de datos SQLite y UI interactiva.
  • 🤖 Batallón: Menú de flota, roadmaps y wizard de creación de tareas adhoc.
  • 🗣️ NLP: Interpreta órdenes en lenguaje natural en español ("anota", "recuérdame", etc.).
  • 🔗 Integración: Comunicación con un "Operador" mediante Inbox Pattern v2.

Uso personal

Esta aplicación no se distribuye a terceros. Solo el propietario (Erwin Risco) la utiliza con su propia cuenta de Google. No recopila, almacena ni comparte datos de otros usuarios.
